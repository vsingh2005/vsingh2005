### Featured Repositories

- **[Equipment Maintenance Planner](https://github.com/vsingh2005/Equipment-Maintenance-Planner)**  
  Manufacturing maintenance application in development. The current foundation provides equipment records, validation, audit history, and conflict checks for concurrent updates. Inspections, work orders, parts, and downtime reporting are on the roadmap.  
  *Stack: Python, SQLite, HTTP/JSON APIs, Pytest*

- **[Delivery Dispatch & Tracking](https://github.com/vsingh2005/Delivery-Dispatch-Tracking)**  
  Logistics application in development. The current foundation stores delivery records and validates updates. Driver assignments, delivery events, exceptions, and proof of delivery are planned.  
  *Stack: Python, SQLite, HTTP/JSON APIs, Pytest*

- **[Product Catalog & Search](https://github.com/vsingh2005/Product-Catalog-Search)**  
  Retail catalog application in development. The current foundation manages validated product records. Supplier imports, variants, inventory records, and search are planned releases.  
  *Stack: Python, SQLite, HTTP/JSON APIs, Pytest*

- **[Quantum Hybrid Neural Network](https://devpost.com/software/quantum-hybrid-neural-network)**  
  AWS Braket and PennyLane hybrid classical-quantum neural network for material hardness classification, integrating PyTorch classical layers with parameterized quantum variational circuits.  
  *Stack: PyTorch, PennyLane, Qiskit, AWS Braket*
